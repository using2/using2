## React Core

> **Vanilla JavaScript 기반 React Core 구현**
>
> 2024.08 ~ 2024.10 · 네이버 부스트캠프 웹·모바일 9기

**Role**

- Frontend

**Tech**

`JavaScript` `Virtual DOM` `DOM API`

### Overview

React의 렌더링과 상태 관리 동작 원리를 이해하기 위해
Virtual DOM, Diffing, State Management를 직접 구현한 학습 프로젝트입니다.

### What I Did

- Tree Diffing 기반 Reconciliation 로직 구현으로 변경된 노드만 실제 DOM에 반영
- Reactive State Management를 설계하여 상태 변경 시 구독 중인 컴포넌트가 자동으로 렌더링되도록 구현
- `innerHTML` 대신 DOM API 기반 렌더링을 적용해 XSS 위험을 줄이는 안전한 업데이트 구조 구현
- 브라우저 이벤트 루프와 렌더링 타이밍을 분석하며 구현 과정을 기술 블로그로 문서화

### What I Learned

- Virtual DOM과 Reconciliation의 동작 원리를 구현 수준으로 이해
- React의 상태 전파와 렌더링 과정을 직접 설계하며 프레임워크 내부 동작에 대한 이해를 심화
- 이후 `contentEditable` 기반 에디터 개발에서 복잡한 DOM 동기화와 렌더링 문제를 해결하는 기반 역량 확보
